## 四、★ 关于"这是不是开源协议"的诚实说明

**本协议属于「源代码公开许可（source-available）」，而非 OSI 定义的「开源许可」。**

```
OSI 的"开源"定义要求【不得歧视任何领域】（含商业领域）→ 允许商业使用
本协议【明确禁止商业使用】→ 因此【不符合 OSI 开源定义】✗

★ 换句话说：本项目是「源码全部公开、可自由学习修改、但不得商用」，
  严格来说应称【非商业源代码公开】，不宜自称"开源"。
  若您在传播本项目时希望表述准确，建议用"源代码公开"而非"开源"。
```

**这是一个自觉的选择，不是疏漏。** 理由见 `NOTICE.md`（与素材授权口径保持一致）。
