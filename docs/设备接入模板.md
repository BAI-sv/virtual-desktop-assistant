# FairyX 外接设备接入模板（三步）

> 2026-10-23 · 眼镜、机器人、汽车、手表……全走这一套

---

## 总览

```
硬件端                     AI 中枢                 FairyX
（ESP32/树莓派/车机）      （可选，用来中转）        （桌面端）
     │                          │                     │
     ├─ POST /device/register ─→│                     │
     ├─ 每 30 秒心跳 ──────────→│                     │
     │                          ├─ GET /devices ─────→│ 适配器发现
     │                          │                     ├─ 菜单显示
     │                          │                     └─ 播报
```

**三条铁律**（全设备统一，代码里已强制）：

1. **上线注册** —— 开机 `POST /device/register` + 每 30 秒心跳
2. **在线才显示** —— 只有 `online=true` 的设备出现在菜单，离线自动隐身
3. **在线才播报** —— 离线一律不播报、拒绝操作，只回「设备未连接」

## 三步接入

### 第一步：硬件端实现「注册 + 心跳」

任何能发 HTTP 的设备都行。**ESP32 示例**（`glasses/esp32_glasses.ino` 的精简版）：

```cpp
#include <WiFi.h>
#include <HTTPClient.h>

const char* WIFI_SSID = "你的WiFi";
const char* WIFI_PASS = "密码";
const char* CENTER    = "http://192.168.124.26:5000";   // 中枢地址

// 这三项是接入的唯一定义，改这三行就能变成汽车/机器人
const char* DEVICE_ID   = "glasses-01";    // 出厂唯一，重启不能变
const char* DEVICE_TYPE = "glasses";       // glasses / robot / car / watch / 自定义
const char* DEVICE_NAME = "我的智能眼镜";

void registerDevice() {
  if (WiFi.status() != WL_CONNECTED) return;

  HTTPClient http;
  http.begin(String(CENTER) + "/device/register");
  http.addHeader("Content-Type", "application/json");

  // actions 可选：不写就按 type 给默认能力
  String body = String("{\"device_id\":\"") + DEVICE_ID +
                "\",\"type\":\""   + DEVICE_TYPE +
                "\",\"name\":\""   + DEVICE_NAME +
                "\",\"ip\":\""     + WiFi.localIP().toString() +
                "\",\"actions\":[\"devices\",\"status\"]}";

  int code = http.POST(body);
  Serial.printf("[心跳] code=%d\n", code);
  http.end();
}

void setup() {
  Serial.begin(115200);
  WiFi.begin(WIFI_SSID, WIFI_PASS);
  while (WiFi.status() != WL_CONNECTED) delay(500);
  registerDevice();
}

void loop() {
  static unsigned long last = 0;
  if (millis() - last > 30000) {     // 30 秒一次，留 30 秒余量
    last = millis();
    registerDevice();
  }
  delay(100);
}
```

**要点**：

| 项 | 说明 |
|---|---|
| `device_id` | **唯一且稳定**，重启不能变。重复注册会覆盖旧的 |
| `type` | 决定默认显示名和能力。`glasses`/`robot`/`car`/`watch`/`speaker` 有内置名；其他值归 `other` |
| 心跳间隔 | **必须 < 60 秒**（`HEARTBEAT_TTL`），超时判离线 |
| `actions` | 可选，设备自报能做什么 |

### 第三步：FairyX 适配器（只有特殊协议才写）

**如果设备走中枢的 `/device/register`，这一步跳过** ——
`glasses_adapter.py` 会发现**所有类型**的设备，不只是眼镜。

**只有走别的协议**（串口、蓝牙、私有 HTTP）才需要写适配器：

```python
# D:\FAIRY\tools\car_adapter.py
# 文件名以 _adapter.py 或 _bridge.py 结尾 → 自动扫描到
import json
import urllib.request


class CarAdapter:
    name = "car"                      # 唯一标识，出现在 ADAPTERS 里
    protocol = "汽车（私有 HTTP）"

    def caps(self):
        return {
            "protocol": self.protocol,
            "actions": ["devices", "status", "lock", "unlock"],
            "needs_account": False,
            "needs_pairing": False,
            "discovery": "http",
        }

    def discover(self):
        """只返回【在线】的设备。连不上就返回空列表，绝不抛异常。"""
        try:
            with urllib.request.urlopen(
                "http://192.168.124.50/devices", timeout=6
            ) as r:
                j = json.loads(r.read().decode("utf-8", "replace"))
        except Exception:
            return []                  # ← 关键：连不上不算错
        return [{
            "id": "car:" + str(d.get("id")),
            "name": d.get("name") or "我的车",
            "kind": "car",
            "online": True,
            "ip": d.get("ip", ""),
        } for d in (j.get("devices") or []) if d.get("online")]

    def state(self, dev_id):
        did = str(dev_id).split(":", 1)[-1]
        try:
            with urllib.request.urlopen(
                "http://192.168.124.50/state?id=" + did, timeout=6
            ) as r:
                return {"ok": True, "result": json.loads(r.read().decode())}
        except Exception as e:
            return {"ok": False, "error": str(e)[:80]}

    def act(self, dev_id, action, params=None):
        if action == "devices":
            return {"ok": True, "result": self.discover()}
        if action == "status":
            return self.state(dev_id)
        return {"ok": False, "error": "不支持的动作: " + action}
```

**丢进 `D:\FAIRY\tools\` 就自动注册，不用改 `device_adapters.py`。**

2026-10-23 起，`device_adapters.py` 会自动扫描：

```
*_adapter.py     ← 眼镜用这个
*_bridge.py      ← 机器人用这个
```

只要里面有类实现了 `name` + `caps/discover/state/act` 四件套，就自动进注册表。

## 常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 名字显示「外接设备」 | `type` 不在内置表里 | 用 `glasses`/`robot`/`car`/`watch`/`speaker`，或让设备自报 `name` |
| 菜单里不出现 | 心跳间隔 > 60 秒 | 改到 30 秒 |
| 整个适配器报错 | `discover()` 抛异常 | 用 `try/except` 包住，返回 `[]` |
| 两台设备互相覆盖 | `device_id` 重复 | 出厂 ID 加随机后缀 |
| `state()` 找不到设备 | `device_id` 含冒号 | 约定 ID 里不要用冒号 |
