# FairyX 功能全景 · 缺口自查与补全路线

目标：**从生活到工作的完整智能助手，且能持续接入新设备并启动调用。**

## 一、现状功能全景（已实测可用）

| 场景 | 能力 | 入口 |
|---|---|---|
| 对话 | 本地大脑 27B/9B，无思考 0.2s，语音唤醒连续对话 | 启动FairyX.bat 喊"Fairy" |
| 视觉 | 看图/反推/OCR翻译（Qwen3-VL，语音一句话触发） | --image / 语音"反推" |
| 生活-天气 | 实时天气+变化提醒 | --weather / --watch |
| 生活-音乐 | 识曲（shazamio 免注册）、歌词、自动歌词 | --songid / --lyrics / --autolyric |
| 生活-翻译 | 中英互译（本地大脑） | --translate / 剪贴板自动 |
| 工作-代码 | 语法纠错+大脑全文分析 | --lint |
| 工作-文案 | 错别字/格式检查 | --check / 剪贴板自动 |
| 工作-视频 | 视频离线字幕（srt） | --subtitle |
| 系统 | 设备发现、4秒全盘扫描、软件/硬件/存储清单 | fairy_extend / fairy_scan |
| 系统 | 鼠标键盘/窗口/截图/文件/命令/计算/搜索/便签 | 悬浮球对话 |
| 部署 | 显存自适应模型部署（独显/核显/内存拆分） | fairy_deploy --auto |

## 三、补全原则
1. **先用免费/开源**：能本地就不联网，能免费 Key 就不付费
2. **每条命令可实测**：加功能必须跑通再交付
3. **设备靠适配器扩展**：新设备 = 在 `device_adapters.py` 加一个类，不用改主程序
