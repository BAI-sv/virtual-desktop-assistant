# 语音素材：请自行准备

**本仓库不包含任何第三方语音素材**（无 .wav / .wem / 语音索引 / 台词文本）。

FairyX 的语音系统设计为「三层降级」，素材全部由**使用者自己提供**：

1. **原声音频**（可选，效果最好）：把你自己的语音文件放进 `voice/voices/`，
   结构为 `voice/voices/<分类>/<任意名>.wav`，然后运行：
   ```
   py -3.12 tools/fairy_ear.py --build-index
   ```
   会生成 `voice_index.json`，Fairy 会优先播放原声。
2. **实时音色克隆**（可选）：自行部署 IndexTTS（bilibili indextts2），
   把参考音频放入 `voice/index_voices/`，语音系统会自动优先使用克隆音色。
   IndexTTS 使用须遵守《bilibili 模型使用许可协议》（非商业自用免费，月活/年收入超 1 亿须申请商业许可）。
3. **TTS 兜底**（默认可用）：`edge-tts` 在线合成（微软 Edge 语音），
   无素材也能说话，但音色为通用语音。

> ⚠️ 请勿将任何游戏的提取音频、角色配音放入本仓库（含公开分支）。
